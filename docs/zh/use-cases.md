# 使用场景

[English](../use-cases.md) · [中文](use-cases.md)

**Speak Helper** 适合 **不想看字、看字吃力，或更习惯用听来获取信息** 的用户。

## 不想看文字，想听内容

- **下班累了** — 不想盯屏幕，复制一段文章或邮件用听的。
- **长文章、长文档** — 分段复制，边听边休息，不必一行行扫读。
- **通知与聊天** — 从微信、Slack、邮件等复制消息即可收听。
- **字号小、界面密** — 老软件、表格里选中文字，快捷键朗读更清晰。

## 视力与阅读辅助

在 **你主动复制或选中** 的文字范围内，帮助 **视力不佳或阅读困难** 的用户听清内容：

| 人群 | Speak Helper 能做什么 |
|------|----------------------|
| **视力不好 / 低视力** | 浏览器、PDF、桌面软件里复制或选中后朗读 |
| **视疲劳、用眼过度** | 部分时间改听 copied 内容，减轻盯屏 |
| **老年人** | 流程简单：复制 → 确认气泡 → 听；家人可一次性帮配好 |
| **阅读障碍** | 听与看结合，降低纯视觉解码压力 |
| **暂时不便阅读** | 手腕受伤、头痛时少看屏幕 |

**重要说明：** 不能替代 NVDA、VoiceOver 等 **专业读屏**（它们负责整个界面导航）。Speak Helper 只朗读 **你交给它的文字**（剪贴板、选中、识图结果）。很多人 **搭配使用**：读屏导航 + Speak Helper 快速听一段任意文字。

## 效率与学习

| 场景 | 典型用法 |
|------|----------|
| **多任务** | 边写代码、做饭、走路时听 |
| **学语言** | Edge TTS 或自定义 API，练中文 / 英文听力 |
| **资料整理** | 从 PDF、网页复制摘录后听一遍 |
| **截图 / 图片** | 复制截图 → OCR 识图 → 朗读（菜单、幻灯片、拍照文档） |

## 适合用 Speak Helper 的情况

- 能看清字，但 **更愿意听**（省事、省力）。
- 只需要 **偶尔朗读**，不是全天候界面播报。
- 经常在 **多个软件** 间切换（复制 / 热键通用）。
- 想用 **免费 Edge TTS** 或自建 **OpenAI 兼容** 语音接口。

## 更适合用其他工具的情况

- **完全依赖读屏导航界面** → 专业读屏软件。
- **整页网页连续朗读、无需复制** → 浏览器朗读扩展或读屏。
- **必须完全离线合成** → Edge / API 后端需联网；已缓存片段可本地重播。
